# Innovators Through History

A Flutter starter app for exploring historical innovators from around the world, with a dedicated African Innovators section.

## Included in Version 1

- Home dashboard
- Global and African innovator profiles
- Search
- Category filtering
- Historical timeline
- Quiz
- Favorites (local in-memory starter)
- Free/Premium presentation
- Advertisement placeholders
- Responsive Material UI

## Run

```bash
flutter pub get
flutter run
```

For Android:

```bash
flutter build apk
```
